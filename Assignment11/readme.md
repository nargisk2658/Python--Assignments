# OpenCV Practical Assignment

## About

This assignment contains basic OpenCV programs that I practiced from the course lectures.

## What I did

* Read and display image
* Save image
* Resize and flip image
* Draw shapes and text
* Apply rotation and threshold
* Apply blur and edge detection
* Read video
* Access webcam

## How to run

1. Install OpenCV:
   pip install opencv-python

2. Run any file:
   python filename.py

## Files

Each file contains one practical based on lecture topics.

All screenshots are taken after running each program and are not edited.

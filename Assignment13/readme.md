# Python Chat Application (Socket Programming with GUI)

## 📌 Project Overview

This project is a simple GUI-based chat application built using Python. It enables real-time communication between a server and a client using socket programming and Tkinter for the graphical interface.

---

## 🚀 Features

* GUI-based chat interface (no terminal interaction required)
* Real-time messaging between server and client
* Supports continuous message exchange
* 'bye' command to exit chat gracefully
* Proper socket closing and cleanup
* Error handling for connection issues

---

## 🛠️ Technologies Used

* Python
* Socket Programming
* Tkinter (GUI)
* Threading

---

## ▶️ How to Run the Project

### Step 1: Start the Server

Open terminal/command prompt and run:

```
python server.py
```

### Step 2: Start the Client

Open another terminal/command prompt and run:

```
python client.py
```

---

## 💬 How to Use

* Type your message in the input box and click **Send**
* Messages will appear in the chat window
* To exit the chat, type:

```
bye
```

---

## ⚠️ Important Notes

* Always start the server before the client
* Ensure both files are in the same folder
* Use the same port number in both server and client files
* If the server is not running, the client will show a connection error

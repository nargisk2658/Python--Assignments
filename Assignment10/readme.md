# Price Tracker

This is a simple Python project where I tried to track the price of a product from a website.

## What I did

* Sent a request to the website
* Used BeautifulSoup to get the price
* Cleaned the price (removed £ symbol)
* Converted it into a number
* Compared it with a target price
* Printed a message based on the result

## How to run

1. Install required libraries:

```
pip install -r requirements.txt
```

2. Run the file:

```
python price_tracker.py
```

## Output

The script prints the product price and tells whether the price is low or high based on the target value.

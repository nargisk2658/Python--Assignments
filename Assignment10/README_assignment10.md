# Web Scraping Assignment

This project contains basic Python programs for web scraping.

I have practiced the following topics:

- Getting data from a website
- Using BeautifulSoup to read HTML
- Sending GET and POST requests
- Using parameters in requests
- Filtering simple data
- Saving data into a CSV file
- Downloading images from the internet
- Creating a simple price tracker

All programs are written in a simple way for learning purpose.
